CROLLIN

설정

페이지 본문을 추출합니다. ChatGPT 전송은 선택 사항이며 API 키는 필요하지 않습니다.

사용 방법

  • 네이버 글이나 인스타그램 글을 연 뒤 확장 프로그램에서 현재 페이지 읽기 또는 URL을 붙여 URL로 읽기.
  • 네이버 PC 주소는 iframe 껍데기라 PostView/모바일에서 본문을 가져옵니다.
  • 인스타그램은 Chrome에 로그인한 세션이 있으면 그 탭으로 읽습니다.
  • 에이전트는 저장소 루트에서 npx crollin URL 또는 node crawl.mjs URL 을 실행합니다.
  • ChatGPT로 보내기는 선택입니다. 먼저 chatgpt.com에 로그인하세요.

중요

이 기능은 공개 API가 아니라 로그인된 ChatGPT 웹 화면의 입력창을 자동화합니다. ChatGPT 로그인 세션이나 비밀번호를 확장프로그램에 전달하지 않습니다.
